## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hash route/UI controls -> authorization | User-controlled navigation and direct browser calls request captain-only screens/actions. |
| local draft -> public preview | A richer editor model is projected into intentionally public configuration fields. |
| browser signer -> relay | One complete authorized state mutation leaves the local device. |
| relay -> accepted revision | Arbitrary, forged, stale, or wrong-author events compete for addressable state. |

| T-01-14 | Spoofing | signed configuration event | high | mitigate | Verify canonical event ID/Schnorr signature, require designated captain author, and test forged/unsigned/non-captain events. |
