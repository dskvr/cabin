## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI/controller -> signer | Browser state requests a captain-only signed create or revision operation. |
| signer -> relay/outbox | One complete authorized public configuration leaves the local draft boundary and may be retained for retry. |
| relay -> repository/parser | Arbitrary, forged, stale, malformed, or wrong-author events compete for addressable accepted state. |
