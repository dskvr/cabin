## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| captain input -> local draft/domain | Free-form text, dates, times, links, IDs, and collection operations enter validation. |
| local draft -> innerHTML UI | Untrusted dynamic values are rendered by the full-root HTML renderer. |
| week timing/form config -> later consumers | Persisted units, field identities, and requiredness become shared contracts for timer and proposal validation. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-07 | Tampering | `src/domain/week.ts` ID-based mutations | high | mitigate | Generate unique immutable IDs, reject duplicates, and test rename/reorder/requiredness preserving answer association. |
| T-01-08 | Tampering | `src/app/App.ts` / `src/ui/html.ts` dynamic markup | high | mitigate | Escape every text/attribute interpolation and pass href values only from `normalizeOptionalUrl`. |
| T-01-09 | Spoofing | UI readiness/disabled controls | high | mitigate | Treat readiness as UX only; Plan 01 builder/parser authorization and full domain validation remain mandatory before signing. |
| T-01-10 | Denial of service | activity/form collections and long text | medium | mitigate | Enforce domain count/string bounds while retaining invalid local draft values for correction and wrapping rendered text. |
| T-01-11 | Repudiation | field identity changes | medium | mitigate | Persist immutable IDs and test answer-key continuity across every presentation/requiredness mutation. |
| T-01-12 | Tampering | persisted timer units | medium | mitigate | Validate whole minutes 1–180, convert once to milliseconds, and test 6+2 and 1+2 phase transitions. |
